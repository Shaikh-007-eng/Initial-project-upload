# Initial-project-upload
This project is a RESTful API built using FastAPI and PostgreSQL that supports user authentication with JWT tokens and implements Role-Based Access Control (RBAC). Users can register with a role (admin or user), log in to receive a JWT token, and use it to access protected endpoints. Admin users can perform all CRUD operations (create, read, update, delete) on a resource called "projects", while normal users can only view them. Passwords are securely hashed using bcrypt. The API uses SQLModel as the ORM to connect with a PostgreSQL database. To run the project, clone the repo, create a virtual environment, install dependencies listed in requirements.txt, and configure the PostgreSQL database by updating the DATABASE_URL in the code. Then, run the FastAPI app using uvicorn. API endpoints include /auth/register for registration, /auth/login for login, /projects (GET) for viewing projects, and /projects (POST) for admin-only project creation. All endpoints require a valid JWT token in the Authorization header
